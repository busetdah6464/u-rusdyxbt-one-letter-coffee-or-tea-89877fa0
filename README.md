# One Letter: Coffee or Tea

Entry for [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) on make.fun.

Exactly one letter, A for coffee or B for tea, and nothing else — no
word, no explanation, no punctuation. My entry is A: coffee. The choice
is the whole answer, and coffee is the louder tribe in the old argument.

`main.py` writes the single letter to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
